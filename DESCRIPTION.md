**Snipit** is a free, offline Windows capture tool (screenshots and screen recording) built around an element picker. Hover any control or window, click, and capture exactly that rectangle. Also region, window, freehand, single-monitor and all-monitor capture with mixed-DPI support, MP4/GIF recording with system sound, microphone and webcam overlay, a capture delay for transient menus, an optional capture-time auto-effect, text copy and sensitivity redaction, and a thin viewer for recent captures.

GitHub repo description: *Offline Windows capture tool: UI-element picker, multi-monitor capture, MP4/GIF recording with audio and webcam overlay, workflows, delay timer, capture-time redaction and text copy, and a thin viewer. .NET 10 + WPF; bundles LGPL FFmpeg for export.*
